Everything Pinch E-Class Record does

Eleven built-in capabilities — from activity-level scoring to portable class-record packaging.

01

Per-Activity Scoring

Record individual student scores for activities and organize them by component — Written Works, Performance Tasks, and Exam. Component percentages are calculated automatically.

02

Per-Term Grade Computation

Each term is calculated separately. Supports 1st, 2nd, and 3rd Terms, with the Final Grade derived from whichever term grades are available.

03

Excel ECR Template Filling

Fills your selected Excel template and term sheet while preserving the original workbook structure — including merged cells, which are written to the correct merge anchor.

04

Learner Management

Manage students with LRN, Last Name, First Name, Middle Name, and Sex. The interface provides built-in sorting and student deletion.

05

Student Import

Import learners from supported files: .xlsx.xlsm.csv.tsv.txt.json. The importer detects LRN, Last Name, and First Name.

06

Class Record Management

Save, reopen, and manage class records as portable .clrx Class Record files — one file per section, easy to back up and share.

07

Embedded ECR Excel

When a class record is saved, the generated ECR Excel file is packaged inside the .clrx file — so your data and output stay together.

08

Summary View

A dedicated Summary tab shows every learner's Name, Term 1, Term 2, Term 3, and Final Grade in a single view.

09

Template Selection

Choose Excel templates manually, or let the application auto-detect templates from its built-in template directories.

10

Local Data Storage

Class and activity data is stored in a local SQLite database inside your user profile — the app folder itself doesn't need to be writable.

11

Splash Screen & GUI

A clean graphical interface with a startup splash screen. The main window stays hidden while the splash displays, then appears when everything is ready.

.clrx
One file. Every term, every learner, every Excel output.

Keeps your Excel ECR intact — even merged cells

Pinch E-Class Record doesn't generate its own spreadsheet format. It fills your template — the one your school already uses — and preserves the workbook structure exactly as it is.

  • Fills the selected Excel template and term sheet directly
  • Handles merged cells by writing to the appropriate merge anchor
  • Preserves original formulas, formatting, and layout
  • Generated ECR Excel is embedded inside the .clrx class record

Pinch E-Class Record is a native desktop application. It runs entirely on your machine and stores its data in your own user profile — so slow connections and remote school assignments never interrupt your work.
